# 午後のすぷりった〜

曲をボーカル・ドラム・ベース・その他に分ける、無料の Mac アプリ。

**ダウンロードと説明：https://revivals47.github.io/gogo-splitter/**

このリポジトリは配布用です（ページと dmg だけを置いています）。
不具合やご意見は [Issues](https://github.com/revivals47/gogo-splitter/issues) へ。

音の分離には [Demucs](https://github.com/facebookresearch/demucs)（Meta・MIT）を使っています。
同梱ソフトウェアのライセンスは [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt) にあります。
