午後のすぷりった〜

曲をボーカル・ドラム・ベース・その他に分ける、無料のアプリ（Mac・Windows・Linux）

ドロップして「分ける」を押すだけ。待っているあいだはメイドさんが走ります。

Mac（M チップ）v0.4.2 ・ 約340MB ・ macOS 12.3 以降 Windowsv0.4.2 ・ 約120MB ・ Windows 10 / 11（64bit） Mac（Intel）v0.4.2 ・ 約350MB ・ macOS 11 以降 ・ 動作確認中 Linux（Ubuntu など・deb）v0.4.2 ・ x86_64

Mac 版は Apple の公証済みで、ダウンロードしてそのまま開けます。Windows 版は初回に注意の画面が出ます（開き方）。
分離に使うモデルは、初めて使うときに Meta の公式サーバーからダウンロードします（くわしく）。

できること

ドロップして押すだけ

MP3・WAV・FLAC・M4A・AAC・OGG・AIFF。何曲でもまとめて入れられます。

分け方を選べる

4パート（ボーカル・ドラム・ベース・その他）、6パート（ギター・ピアノも）、「ボーカルとそれ以外」の2つ。

その場で聴ける

終わったらパートごとにミュート・ソロ・音量。耳コピや練習にそのまま使えます。

曲はどこにも送らない

処理はお使いのパソコンの中だけ。アカウントもアップロードもありません。

書き出しも選べる

WAV（24bit）・FLAC・MP3。元の曲の隣に、曲名のフォルダで作ります。

待ち時間も楽しく

処理中はメイドさんが走ります。残り時間も出るので、いつ終わるかが分かります。

使い方

  1. ダウンロードした dmg を開き、「午後のすぷりった〜」を Applications フォルダへドラッグします。
  2. アプリを開いて、曲のファイルを画面にドロップします。
  3. 分け方を選んで「分ける」を押します。メイドさんが走り終わったら完成です。

時間の目安（5分の曲）

M チップの Mac1分前後（Mac の GPU で処理します。MacBook Air M1 で約45秒の例）
Windows・Linux（NVIDIA の GPU）十数秒（GPU 用の部品を入れたとき。RTX 4070 で3分の曲が約10秒）
Intel の Mac・GPU なしの PC数分〜10分ほど（CPU で処理します）
4パート・高品質上の約4倍

1時間を超えるような長い曲は、メモリが足りなくなることがあります。

よくある質問

安全ですか？

Mac 版は Apple の公証（ノータリゼーション）を受けた正式な署名つきのアプリです。曲はお使いのパソコンの中だけで処理し、外へは送りません。インターネットを使うのは、起動時に新しい版があるかを確かめるとき（このページの版番号を読むだけです）と、モデルや GPU 用の部品を初めてダウンロードするときだけです。

分離のモデルはどこから来るの？

Meta が公開している Demucs の学習済みモデル（重み）を使います。このモデルはアプリには入っておらず、分け方ごとに初めて使うときだけ、確認の画面を出してから Meta の公式サーバーからお使いの Mac へダウンロードします（4パート 約84MB・6パート 約55MB・4パート高品質 約320MB）。
このモデルは、Meta が研究目的に限って公開しているものです（開発者の説明）。使い方はご自身の判断でお願いします。Demucs のプログラム自体は MIT ライセンスです。

Windows で「Windows によって PC が保護されました」と出ます

個人で作っているアプリで、Windows 用の有料の署名を付けていないため、初めて開くときに出ます。「詳細情報」を押すと出てくる「実行」ボタンで開けます。2回目からは出ません。

NVIDIA の GPU で速くできますか？（Windows・Linux）

できます。NVIDIA の GPU がある PC では、画面の上に「GPU 用の部品を入れる」が出ます。押すと、GPU で計算するための部品（CUDA 版の PyTorch・約2.5GB）を PyTorch の公式サーバーからダウンロードして入れます。空き容量が約8GB 要ります。入れたあとは自動で GPU を使い、CPU より10倍以上速くなります。NVIDIA のドライバーが古いと入れられないことがあります。

Linux での入れ方は？

Ubuntu・Debian 系なら、ダウンロードした deb を sudo apt install ./gogo-splitter_0.4.2_amd64.deb で入れます。メニューに「午後のすぷりった〜」が出ます。

Windows・Linux で M4A が読めません

Windows と Linux では、M4A・AAC などを読むのに ffmpeg を使います（アプリには入っていません）。ffmpeg を入れるか、MP3・WAV・FLAC・OGG に変換してから使ってください。Mac はそのまま読めます。

分離の精度は？

Meta の音源分離 Demucs（htdemucs）を使っています。ボーカルとドラムは特にきれいに分かれます。曲によっては、ほかのパートの音が少し残ることがあります。

Intel の Mac でも使えますか？

Intel 版も用意していますが、作者の手元に Intel の Mac がなく、まだ実機で十分に確かめられていません。うまく動かなかったら、下の連絡先へ教えてください。

うまく動かないときは？

画面の「ログを開く」で出てくる worker.log を添えて、下の連絡先へ送ってください。

名前の由来は？

MP3 エンコーダーの名作「午後のこ〜だ」へのオマージュです。敬意をこめて。

ご意見・不具合のご連絡は GitHub の Issues へ。
